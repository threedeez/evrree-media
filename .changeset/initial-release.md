First release of `@evrree/media`: `createMediaClient` with S3-compatible (AWS S3, Cloudflare R2,
DigitalOcean Spaces, MinIO), local-disk, in-memory and custom providers; uploads with size, type
and magic-byte validation and automatic multipart; presigned browser uploads
(`@evrree/media/client`); signed URLs; and a NestJS module (`@evrree/media/nestjs`).
